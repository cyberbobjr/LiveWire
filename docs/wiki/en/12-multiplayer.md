# Multiplayer

## Multiplayer

Production, stock, states, failures and experience are computed by the **server**. The client displays and sends requests, which the server re-checks.

- Shared installations follow the vanilla safehouse rules.
- The software may lag up to 10 game minutes.
- If the server pauses when empty, the installation pauses too.
- Vanilla generators are unchanged. If a generator and an inverter cover the same appliances, both pay.
- Debug tools: `-debug` in single player, admins in multiplayer.

## Status

Version 1.6.1 was published on the Steam Workshop on 2026-10-25. Static checks and offline regression tests cover the new work; the supplied in-game screenshots confirm the equipment panels visually. Earlier single-player and Windows multiplayer campaigns cover the snapshots documented in the report; the latest changes still need a complete multiplayer pass. Linux is not validated. See the [validation report](../../annexes/tests/validation.md). Balancing values remain starting values.
